# Museologías Expandidas — prototipo

Prototipo navegable del sitio (HTML, CSS y JavaScript, sin dependencias).

- `index.html` — Home
- `proyectos.html` — Explorar proyectos
- `proyecto.html` — Detalle de un proyecto de ejemplo

## Ver en local

```
node serve.js
```

y abrir http://localhost:5500

Contenido provisorio: proyectos, descripciones, imágenes y correo de contacto son de prueba.
